KEPUTUSAN ARSITEKTUR TERKUNCI (D1–D7)
==============================================================================
D1. STOK OTORITATIF = `inventory_balances`. `products.stock` & `product_variants.stock`
    = agregat turunan (di-sync InventoryService). Semua mutasi menulis
    inventory_balances + stock_mutations (transaksi DB + lockForUpdate).
    EKSEKUSI: (a) backfill awal inventory_balances dari stok lama (T12.1a);
    (b) refaktor penulis stok lama (T03, T14.1) -> [PARTIAL].
D2. STATUS = kolom string + tabel lookup untuk label/badge (order_statuses,
    payment_statuses). Tidak migrasi penuh ke FK.
D3. BERAT BAKU = GRAM. `orders.total_weight` dikonversi + backfill (T12.1b);
    konsisten dgn products.weight & product_variants.weight_grams.
D4. UANG = DECIMAL(14,2) + pembulatan 2 desimal (half-up). Mayoritas sudah;
    standardisasi presisi menyimpang (T12.1c).
D5. KONSOLIDASI DUPLIKAT: products.min_stock->stock_minimum (T12.1d),
    orders.phone_number->phone (T12.1d), products.warehouse_bin->warehouse_bins
    (T12.1d), products.cost_price vs product_variants.current_cogs (T18.3),
    users.role+user_roles sinkron (T24.5), expeditions.(service,etd,cost) vs
    expedition_services (T06.5). Semua disertai migrasi + backfill.
D6. ZERO STATIC ENUM: stock_mutations.type = {in,out,adjust,reserve,release,
    transfer,opname,return}; status returns/reviews/transfers pakai lookup/label.
D7. STORAGE = Cloudflare R2 (disk `s3`). Aset publik (gambar produk/avatar) =
    bucket publik. Dokumen SENSITIF (payment_proof, invoice vendor, proof bayar)
    = bucket PRIVAT + akses via `Storage::disk(...)->temporaryUrl()` (presigned).
    DILARANG URL publik permanen untuk file sensitif (T21.3).
D8. SUMBER KEBENARAN PEMBAYARAN = tabel `payments` (T07.5). Kolom
    `orders.midtrans_*`/`payment_*` menjadi TURUNAN/legacy yang di-sync dari
    `payments` (bukan sebaliknya). Semua laporan/agregasi memakai `payments`.
D9. TANPA TIER MEMBERSHIP: semua pelanggan FLAT (membership_tier = "Member").
    Kolom `membership_tier` tidak dipakai untuk aturan bisnis. Task tier DIHAPUS.

CATATAN KEPUTUSAN LAIN:
- D2: kolom `status` (string) OTORITATIF; `status_id` di-sync sebagai referensi label.
- D1 backfill: seluruh stok lama masuk gudang `is_primary` + catat
  `stock_mutations` saldo awal agar kartu stok konsisten.
- D3 konversi berat: nilai `orders.total_weight < 100` dianggap KG -> dikali 1000;
  sisanya dianggap sudah gram.
- [KEPUTUSAN DIBUTUHKAN] durasi expiry poin (usulan default 12 bulan, via config G6).
- [KEPUTUSAN DIBUTUHKAN] aturan refund: usulan Midtrans untuk channel online,
  manual untuk transfer manual (via config G6).
