\flowmeta{A13}{Buku Kas, Rekening dan Jurnal}{Admin}

\begin{flowsection}{Tujuan}
Mencatat arus kas masuk/keluar, rekening, dan jurnal double-entry.
\end{flowsection}

\begin{flowsection}{Prasyarat}
Login sebagai admin dengan peran yang memiliki akses modul ini.
\end{flowsection}

\begin{flowsection}{Langkah}
\begin{enumerate}
  \item Buka Buku Kas \&  Transaksi (/admin/transactions).
  \item Tambah transaksi: jenis, kategori, rekening, nominal.
  \item Lihat Jurnal Umum (/admin/journal) untuk rincian double-entry.
\end{enumerate}
\end{flowsection}

\shot{gambar/admin/a13-1.png}{Halaman Buku Kas, Rekening dan Jurnal pada Panel Admin}{fig:a13-1}

\begin{flowsection}{Pencatatan Otomatis}
Pembayaran pesanan (termasuk \textbf{Midtrans}) dicatat otomatis sebagai kas
masuk (kategori \emph{Pembayaran Pesanan}) beserta jurnal pendapatan. \textbf{Fee
transaksi Midtrans} dihitung \textbf{per kanal} (Fee BCA VA / BNI VA / BRI VA /
Mandiri VA / QRIS: persen + nominal tetap) dengan fallback ke tarif global, lalu
dicatat sebagai beban gateway (Debit 6200, Kredit Bank) dan memengaruhi nilai
bersih (\texttt{fee\_deducted}/\texttt{net\_amount}).

\textbf{Fee otomatis (SNAP):} bila \emph{SNAP Fee Sync} diaktifkan (Client ID +
RSA Private Key SNAP diisi admin), sistem menarik \textbf{fee per transaksi}
langsung dari \textbf{Midtrans SNAP Transaction History API} melalui perintah
terjadwal \texttt{midtrans:sync-fees} (tiap jam) — tanpa input manual. Tarif per
kanal hanya dipakai sebagai estimasi/fallback bila SNAP tidak aktif.
\end{flowsection}

\begin{flowsection}{Hasil yang Diharapkan}
Arus kas dan jurnal tercatat rapi untuk laporan keuangan.
\end{flowsection}

\begin{flowsection}{Penanganan Error dan Kasus Khusus}
\begin{itemize}
  \item Nominal \&  rekening wajib valid.
\end{itemize}
\end{flowsection}
